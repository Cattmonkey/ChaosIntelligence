计算能力与现实边界

抽象核心具有条件、递归和无界数据，可编码两寄存器机。实际运行采用有限的计算步数、内存和时间预算。智能体的提示词负责定义行为，不能单独构成图灵完备性的证明。

图形层采用无环数据流；迭代与条件分支在函数节点中表达。平台变更原子提交，正在执行的版本快照保持稳定。

CHAOS · QUICK START
从一个文件开始。
  1. 在左侧“文件”打开或新建 .chaos 模块，直接编辑源码。
  2. 从“运行”菜单设置输入，确认入口文件，再用顶部“运行”保存并执行；底部自动显示结果。
  3. 打开“助手”描述编程需求；先查看提案差异，再应用修改。
  4. 文件标签旁可直接格式化或检查代码；“编辑”“视图”“运行”菜单提供更多操作。“智能体”菜单集中管理团队、会话与持续任务。命令面板仍支持 ⌘ / Ctrl Shift P，⌘ / Ctrl P 快速打开文件。
  5. 需要可视化工作流时，打开“画布”，拖拽模块并点击节点设置属性；从节点输出端口拖到另一个节点的输入端口，连接数据流。
