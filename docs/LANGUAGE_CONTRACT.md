# 语言核心的组合合同

Chaos 的目标是图灵完备、语义自洽、可组合的智能体函数语言。它用同一运行时组合函数、数据、模式、完整多返回值、同步／异步控制和有权限的宿主效果，让工程师用稳定的语言与库构造复杂程序：常规业务写成函数和库，智能决策写成一等 Agent，有状态长期工作使用 Bot／Goal，外部动作通过受控工具与设备能力完成。无需为每类业务增加语法或另一套执行器。

当前支持范围以本合同、各专题文档和对应验收为准。抽象计算核心的图灵完备论证见[语义](SEMANTICS.md)：去掉资源上限后可编码两寄存器机；实际运行始终受步数、时间、数据大小／对象图等既有资源上限和权限限制；这些限制不等同于统一的语言堆或进程 RSS 预算。可复用同步 Continuation、无源码可执行 IR 和独立运行时库已纳入组合模型。Python／Lisp 用于比较语义选择与生态差异，覆盖其全部功能不属于本语言的发布验收条件。通用机器码 AOT、独立 GC、跨目标 ABI 和任意活栈迁移仍是独立技术目标；这些边界继续如实记录。

## 一次发布的有限验收

验收针对明确版本、支持范围和真实执行证据。下表规定需要证明的组合关系，不表示当前每项已经通过，也不保证任意程序终止、模型判断正确或外部任务成功。

| 范围 | 需要的证据与边界 |
| --- | --- |
| 计算核心 | 函数、递归、条件、状态与数据能组合执行；原求值次序、作用域、完整结果和错误语义一致。已有两寄存器机示例及普通语言实现的可替换指令表提供编码与逐步对应见证；有限示例与测试不能替代抽象论证。 |
| Agent 一等值 | Agent 可作为参数、返回值和组件，通过同一函数调用与契约组合；声明不调用模型，真实调用经过宿主 handler。确定性 provider／tool 夹具验证效果和权限拒绝，付费模型另行授权。 |
| 效果与生命周期 | Task／流保持冷构造、显式等待／消费、多结果、取消和资源清理；源码、IR、解释和支持的编译路径不重放已提交前缀，也不因控制值扩大能力。 |
| Goal／Process 与指导 | 长期工作使用原 checkpoint、lease、版本事务和邮箱；指导的收到、采用及最终结果有真实事件。不确定外部效果须协调，不能把活栈或一次性资源当作可重放数据。 |
| IDE／CLI／SDK 与网页 | 共享同一语言和运行快照，源码／结构 IR 往返、公共接口、事件／指导／取消及错误合同一致；界面和提示词不另建解释器或判定语言完成。 |
| 安装与包 | wheel／portable 的运行时、资源与文档精确对应候选版本；独立消费者与安装烟测验证真实导入和所声明路径，保全现有源码、用户配置及数据。包通过不等于服务已更新，软件 Robot 回执不等于硬件达成。 |

现有本地计算示例可用 `chaos run examples/counter-machine.chaos` 运行，预期为 `{a: 0, b: 42}`；它不调用模型或设备。Agent 的确定性宿主示例见[智能体函数语言](AGENT_LANGUAGE.md)，指导、事件和终端控制见[SDK](SDK.md)，安装及独立包边界见[安装与部署](INSTALLATION.md)。这些入口可分别核验，再验证跨入口的同一语义；不以目录数量、版本号或测试总数宣布全部完成。

## 依赖关系与统一入口

| 基础 | 组合能力 | 必须保留的合同 |
| --- | --- | --- |
| 函数、闭包、Cell 与参数契约 | 高阶函数、递归、AgentTool／Team 角色、策略工厂 | 从左到右求值；函数形成时名称快照；已存在 Cell 共享；不把后续声明追溯加入旧闭包 |
| AST、卫生宏、IR、Code／Program | 生成、分析、链接和运行同一语言程序 | 同一解析／展开／执行语义；显式绑定与所有权；旧 artifact 加载重新校验源码和计划；executable 加载已展开的封闭 IR；两者均不序列化活值或提供机器码 AOT |
| 零／单／多完成 | producer／receiver、尾调用、Task 最终值、控制转移载荷 | 零值、单个 null、一个 List 和多个值不同；完整次项仍受权限与契约检查 |
| prompt／escape／wind | 动态退出、保护与清理；定界后缀保存和重复组合 | 目标身份；原 error_context／优先级；每次新 wind 激活只承担一次退出义务 |
| 冷 Task／Generator 与原调度器 | 并发角色、流、取消与资源排空 | 构造不执行；await／消费才开始；借用不增加取消或关闭权；不跨 holder 搬运保存控制段 |
| Context／能力／预算／资源租约 | Agent、Bot、Computer／Device／Robot 和长期 Goal | 每次实际准入；原命令一次性与 lease 协调；控制值不能扩大权限、复制租约或撤销已提交效果 |

当前共享描述目录为335个全局 Native／381项完整 NativeSpec，IDE、源码／IR、SDK／CLI 与无界面入口读取同一合同。目录总数不是完整性百分比；用户遮蔽名称和宿主权限仍由运行时决定。

## 可复用后缀怎样工作

`capture_continuation(tag,receiver)` 在最近同身份提示中保存准确支持的同步解释帧，在原位置调用 receiver。receiver 返回后初始后缀运行；`k(*items)` 以后每调用一次，就在当前调用者之上运行一份新后缀，完整结果返回该调用者。receiver 可显式 abort 退出原提示，保存值不借用已关闭的旧范围。

原前缀不会因恢复重跑。每次有新的可变执行容器和活动命名空间外壳，既有 Cell／普通值身份仍共享。capture 之后建立的局部和返回闭包保留本次后缀的绑定；复用不是整个堆的快照。wind 保留调用者原激活，并为保存段重新 before／after；失败展开只清理已成功进入的激活，替换错误成为后续外层清理的当前上下文。

准确的语法、完整结果、权限、额度和屏障见[Continuation](CONTINUATIONS.md)；旧[动态 escape](CONTROL_PROMPTS.md)仍是活动范围出口，不改成多次恢复。

## 只用语言组合复杂功能

将复杂工作拆成四个明确阶段：用普通函数和模式定义策略与合同；用 AgentTool／Team／Bot 或 Task 调用实际提供方；在资源范围内完成观察与一次性命令并关闭；将得到的普通数据交给可重复的同步决策后缀。长期执行由已有 Goal checkpoint／lease、录制 Skill、Plan 调度和 Process 事务承担，continuation 只保存同次运行内的控制段。

例如，已完成的 Agent 回答与软件 Robot 回执可作为函数输入，然后捕获计算分支以尝试多个参数。只改变参数的多次后缀不再次调用之前的 Agent 或 Robot；如果把效果写在后缀里，则每次 k 都会重新请求宿主准入。未知完成的外部动作不能自动重试；sent 不证明物理目标达成。

无需新增应用端解释器、把提示词当控制语法、或为 SDK／CLI 写另一套语义。源码、Code／IR 与 artifact 中的程序都在本次 evaluator／epoch 内创建真实控制值；HTTP JSON 不提供跨请求 invoke-by-id。

## 运行入口与观察

模块可以先编译再分发。`compile_objects(..., libraries=objects)` 只为当前源码包运行前端，依赖库提供已验证的展开 AST；`link_objects` 和 `load_executable` 不运行源码前端或模块初始化。模块导出的函数、类、数据与 Agent 仍在每次运行中创建，由原运行时处理闭包、权限、异步和资源作用域。

独立对象采用内容绑定：客户端记录依赖对象的精确身份，替换实现后须重新编译客户端。它不是允许任意二进制替换的稳定符号 ABI。发布者显式使用 `macro_interfaces=True`（CLI `--macro-interfaces`）产生带纯宏接口的 v3 对象，客户端可在没有库源码时调用其导出宏；私有帮助宏、定义处导入和卫生绑定由受验证的阶段 AST 保留。旧 v1／v2 库只有宏导出名字时仍明确拒绝外部调用，不猜测缺失定义。阶段接口不保存活 Env／闭包，不授予工具、模型或设备权限。

默认 CLI、实时 `chaos run --stream`、POSIX `--interactive`、SDK 和网页使用同一 Run 身份与事件。终端指导通过原邮箱和 Bot 检查点采用，不能直接修改活动函数栈或绕过权限。长生命周期状态由 Process／Goal 管理；本地命令退出的取消与清理不能冒充跨重启恢复。具体输出和控制见[SDK](SDK.md)。

原生代码物理制品也不携带运行权限。可信宿主可通过 SDK 的 `NativeObjectCache` 显式保存并认证当前标量／flow 后端发射的本机对象，在兼容进程中重新链接；每次仍检查当前函数、后端、守卫和逻辑检查点。默认磁盘缓存关闭，源码／HTTP 镜像不能授予缓存信任或提供任意机器对象。对象复用保留原 Module／Agent／Bot／Robot 运行时，并不构成完整机器码 AOT、跨架构 ABI、活栈持久化或独立 GC。具体信任边界见 [SDK](SDK.md#宿主私有原生对象缓存)。

Flow 的真实 native／portable 事件还共用调用域中的代际根槽：派发校验类型化包并解析实际载荷，函数／作用域／结果／待决引用在关闭时随本次域退役。它不改变语言调用、旧编译查询或权限合同，不允许外部 root token 取得活值；这项局部存储合同也不是全语言堆预算或独立 GC。

## 明确的支持边界

当前 continuation 仅支持同 evaluator／活动 epoch／逻辑 holder 的显式登记同步解释帧，包括普通调用、操作数、块／分支、while、普通保护主体和 wind body。调用权限取保存上限、当前调用者与投影视图的交集；定义、完整参数、图像结构与预算在安装前检查。

Task／stream、活动编译 FlowState、for 句柄、资源／退出栈、TaskGroup、Mode／Goal lease／录制、未知 native 桥和正在进入／退出／展开的状态明确拒绝捕获或跨边界调用。它们原本的功能仍可正常使用，只不能把活动线性状态复制进后缀。硬取消／ResourceLimit 保持原优先级与清理规则。跨请求／进程持久化、通用异步 continuation、自动事务重放、自举、完整外语包兼容、GC 和通用 AOT 仍须分别实现和验收。


编译文件可通过 `Framework.start_executable`／`Client.start_executable`／`chaos executable start` 使用原宿主运行时。Agent／Bot／Goal 和设备效果保留项目授权及原资源生命周期；实际镜像和授权项目分别记录，`current_program` 不伪造缺失源码。源程序与镜像共用事件、实时指导和取消协议，完整入口与传输限制见 [SDK](SDK.md#无源码加载的可执行文件)。
