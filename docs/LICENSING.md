## 可以怎样使用

可以学习、运行、修改和分发受许可的原创代码，也可以商业使用；分发时必须保留版权、完整许可和适用的第三方声明，不得通过重新授权取消禁止训练条件。正常调用模型、用 AI 辅助理解和修改代码，以及用本语言运行 Agent／Bot 都仍然允许，前提是不把受保护材料纳入模型训练。

限制针对项目提供的原创源码、文档、示例等材料及其衍生内容，不自动扩展到用户独立编写的应用、自己的数据或不包含受保护材料的程序结果。可以把本语言作为工具处理自己的数据，包括独立数据上的训练任务；不能把本项目源码作为该训练的教材或数据。将代码交给外部模型作编程辅助时，应选择不将输入用于训练的服务配置或协议。

## 不允许的训练用途

未经相应权利人另行书面许可，不得将受保护材料或由其构建的代码片段、表示及衍生训练数据用于模型预训练、微调、蒸馏、强化学习或其他模型训练，也不得为这些目的收集、制作、出售或分发数据集。免费、商业、研究或非商业目的不自动构成例外。

禁止训练不等于禁止所有 AI 功能；只作推理、检索或开发辅助而不训练模型的正常操作仍适用许可中的允许范围。需要不同授权时，先通过 [Cattmonkey 的 GitHub 账户](https://github.com/Cattmonkey)联系权利人。

## 托管平台与限制的边界

这是一项源码可见许可，不是 OSI 定义的开源许可：OSI 的定义不允许按用途领域限制使用。[OSI 定义](https://opensource.org/osd)

许可表达权利人的授权条件，不是防抓取技术，也不保证第三方遵守。GitHub 当前服务条款（查阅于 2026-10-23，页面生效日期 2026-04-27）D.4 包含向 GitHub 及关联方授予模型训练权利；J.3 明确个人 AI 输入／输出的退出选项不覆盖 D.4–D.8 或公开仓库内容。仓库内新增许可不能被表述为自动覆盖了这些另行授予的平台权利。[GitHub 服务条款](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service)

因此，要求连托管平台也不得训练时，不能仅靠“上传 GitHub 再附一份禁止训练 LICENSE”实现。发布者需要先核对适用的平台协议、账户协议与发布方式，再决定是否上传源码。第三方独立许可、法律允许的使用和权利人另行授予的权利也须分别判断。
