## 5 位科学家，3 位工程师

人物是语言角色的拟人化。职责通过普通函数、Agent 值、工具绑定与执行记录表达，外观不赋予程序额外权限。

| 角色 | 专业 | 函数职责 |
| --- | --- | --- |
| 序 / SERA | 理论物理 | 提出候选结构与可检验假设。 |
| 格 / GRID | 计算数学 | 采用共同数据与指标，调用数值函数。 |
| 镜 / MIRROR | 统计审查 | 检查独立验证、反例与结论边界。 |
| 界 / DELTA | 实验设计 | 改变初值、噪声与检查条件，提出后续实验。 |
| 识 / NOEMA | 脑神经科学 | 检查简化兴奋模型，区分活动曲线与机制解释。 |
| 链 / LINK | 语言与编译工程 | 将方程封装为函数，连接可调用智能体与工具。 |
| 锚 / ANCHOR | 运行时系统工程 | 关注 Task／流、预算、权限、指导采用和证据生命周期。 |
| 衡 / PULSE | 控制工程 | 设计输入脉冲，记录响应，提出下一轮输入条件。 |

[可运行的 8 角色源码](../../../examples/research-lab/research-team.chaos)使用本系统配置的模型连接。影片中的争论是经过编排与审阅的叙事，不是一次自主研究对话的原样录屏，也不展示模型内部推理。

## 两个实验，复用同一个数值函数

**Lorenz：一个分量吻合，不等于整个系统成立。** 在加入固定噪声的合成状态上估计导数，再分别拟合仿射线性与预设二次候选。线性候选的训练 `dx/dt` R² 为 **0.99985**，但它没有因此通过整体动力系统检验。三组未参与拟合的初值，在无量纲 `t=0–2` 内，线性／二次候选的轨迹 RMSE 分别为：

| 独立初值 | 线性候选 | 二次候选 |
| --- | ---: | ---: |
| `[-8, 7, 27]` | 20.3030 | 0.08932 |
| `[5, 5, 20]` | 11.3654 | 0.04767 |
| `[-12, -5, 35]` | 14.7813 | 0.07845 |

这些积分和误差归约由 Chaos 执行，NumPy 独立复核；回归、平滑与高精度参考由宿主 NumPy／SciPy 完成。影片里的邻近初值分离曲线由 SciPy 对同一已知真方程计算，说明长期轨道分离不能单独判错。两网格步长减半检查也已执行，但不构成严格收敛阶或无限未来精确性的证明。[参数与验证记录](../../../examples/research-lab/experiment.json)

本例复算已知合成系统，在预设候选库中辨识模型；不是无先验发现新的物理规律。理论背景见 [Lorenz（1963）原论文](https://journals.ametsoc.org/doi/abs/10.1175/1520-0469%281963%29020%3C0130%3Adnf%3E2.0.CO%3B2)及 [Brunton、Proctor、Kutz 的稀疏辨识论文](https://arxiv.org/abs/1509.03580)。

**FitzHugh–Nagumo：换一个动力学闭包，继续使用同一个 RK4。** 两个状态表示简化的兴奋与恢复，在同一模型上施加弱／强脉冲，记录输入结束后的响应。两条轨迹与 SciPy 独立参考的联合状态 RMSE 约为 **1.20×10⁻¹¹** 和 **7.27×10⁻⁸**。[语言源码](../../../examples/research-lab/neural/excitation.chaos) · [验证记录](../../../examples/research-lab/neural/verification.json)

所有时间和状态均无量纲。这是定性机制的合成示例，不是完整大脑模型、真实脑信号或临床结论；没有证明严格兴奋阈值，也没有完成对多个机制的自动辨识。选用形式与参数是本示例的选择，不能当作原论文逐项复刻。背景见 [FitzHugh（1961）原论文](https://jxshix.people.wm.edu/2009-harbin-course/classic/FitzHugh-1961.pdf)与 [Nagumo 等（1962）原论文](https://doi.org/10.1109/JRPROC.1962.288235)。

## 模型说的话，同样需要检验

另行执行的 8 角色模型示例完成了 **8/8 个角色调用与 8/8 次语言工具回执**；16 次模型请求均返回成功。每次工具调用实际复算一个 Chaos RK4 步，再读取已验证实验记录。它不是重新执行整套研究，也不能替代数值核验。

这次文本验收**未全部通过**：2 条未通过影片额外设置的 **80 总字符展示限制**，另有 1 条指标措辞需要审校。原提示要求的是 80 汉字以内；这两条的汉字数均未超过该要求，不能把额外展示标准未通过说成违反原指令。原始失败状态保留，没有用重试抹去问题。影片对白单独编写、审阅和配音，不将这些未经修正的回答当作科学结论。[公开验收摘要](../../../examples/research-lab/evidence/agent-acceptance.json)

## 制作来源

| 层次 | 来源与处理 |
| --- | --- |
| 人物与场景 | 为本片生成的虚构 CG 角色及场景，不使用真实科学家肖像或背书。人物动作与身份展示属于叙事。 |
| 配音 | 8 角色加 1 位旁白，共 9 个百度语音合成音色；使用供应商音色，未进行声音克隆。对白是审阅后的脚本。 |
| 音乐 | 为本片编写并合成的原创配乐，没有使用第三方录音采样；按场景和对白混音。 |
| 科学图 | 从实际实验数组绘制，保留变量、时间单位、训练／独立验证边界与来源。不是让影像生成模型编造图表。 |
| 程序与运行 | 真实源码、工具回执与公开事件用于对应展示；语言结构动画与剧情时间线不冒充后台真实执行负载。 |

影片介绍语言的可组合能力，不是 GPU 性能基准，不宣称全语言 GPU 编译或无限自主科研。复现时需要 Python 3.9+ 运行时；完整参考实验另需 NumPy／SciPy，普通函数例子不需要模型密钥。
